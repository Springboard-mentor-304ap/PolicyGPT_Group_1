# PolicyGPT

**PolicyGPT** is a government policy and scheme intelligence platform that helps users explore policies, discover government schemes, compare options, and check eligibility in one place.

🌐 **Live Website:** [https://policygpt-india.vercel.app/](https://policygpt-india.vercel.app/)

## ✨ Features

- 🔍 **Policy Search** – Explore government policies.
- 📋 **Scheme Search** – Discover government schemes.
- ⚖️ **Compare** – Compare policies and schemes.
- ✅ **Eligibility Checker** – Check eligibility for government schemes.
- 📊 **Dashboard & Analytics** – View relevant insights and statistics.
- 🤖 **AI Chatbot** – Get assistance with policies and schemes.
- 👥 **Role-Based Access** – Separate features for different user roles.

## 🛠️ Tech Stack

- Frontend: Angular, React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL (Supabase)
